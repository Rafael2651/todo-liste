Desenvolvi uma aplicação de gerenciamento de tarefas (to-do list) para ajudar usuários a organizar suas atividades diárias e aumentar a produtividade.
O objetivo principal era criar uma solução simples e eficaz para o problema comum de esquecimento e sobrecarga de tarefas, permitindo que os usuários registrem e gerenciem suas pendências de forma centralizada.
